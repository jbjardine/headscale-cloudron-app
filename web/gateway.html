How it works

Your cloud environment joins official Tailscale. This gateway connects the services below through a separate Headscale identity.

Only the TCP services you choose are forwarded. Headscale and Tailscale access policies apply alongside these settings.

Use a dedicated Headscale user and allow it to reach only the destination machines in your Headscale policy.

2. Choose accessible services

Each service has a port on the gateway and a destination on a registered Headscale machine.

Register a machine in Headscale before adding a service.

3. Set access limits

One per line. An empty list blocks all service connections. Use the cloud machine's Tailscale address, or a network you explicitly trust.

Shared by all services and both directions. 0 means unlimited.

4. Connect your cloud environment

  1. Save the gateway settings and wait for its Tailscale address above.
  2. Create a separate reusable official Tailscale auth key for your cloud environments, then add it to their VPN settings.
  3. Allow the gateway's IPv4 address in the cloud environment's network settings if its policy requires it.
  4. Connect to the gateway address and the service port chosen above.

A Headscale key cannot be used in a cloud VPN field that only accepts official Tailscale keys. Enrollment key expiry prevents new registrations; existing machine sessions follow their own expiry settings.
